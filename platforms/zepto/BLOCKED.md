# BLOCKED: Zepto — CloudFront 403 (datacenter VPS IP)

**Date tested:** 2026-05-21 from the Hostinger VPS (datacenter IP).
**Verdict:** Blocked at the edge. **Needs a residential proxy.**

## Exactly what we saw
Two probes, both `HTTP 403` from CloudFront before any page JS ran:

```
HOME status: 403
server hdr: "CloudFront"
body: "403 ERROR  The request could not be satisfied.
       Request blocked. We can't connect to the server for this app or website
       at this time... Generated by cloudfront (CloudFront)  Request ID: ..."
SEARCH status: 403   (https://www.zeptonow.com/search?query=jivo — same 403)
LOCALSTORAGE keys: []   COOKIES: []   (page never initialised)
```

## What we ruled out
- **Not** a User-Agent / fingerprint problem. Tried both a spoofed macOS-Chrome UA
  and the real Linux Chrome UA + full client-hint headers (`Accept-Language`,
  `Accept`, `Upgrade-Insecure-Requests`). **Same 403 every time.**
- **Not** a missing-location issue — the block is at the CloudFront WAF, before
  the SPA loads, so we never reach the location picker.
- The block is **IP-reputation based**: AWS CloudFront WAF is rejecting the
  datacenter IP outright. This is the "does it catch us" test failing.

## What's needed to unblock
- A **residential (or mobile) proxy** with an Indian exit IP. Route Playwright
  through it (`chromium.launch({ proxy: { server, username, password } })`).
- Then run `./run.sh zepto`. `scrape.js` has a **403 guard** that throws
  `BLOCKED: CloudFront 403` per pincode — if that fires under the proxy, the
  proxy IP is also flagged; if it loads, tune the (currently UNVERIFIED) card
  selectors against the real Zepto DOM and confirm `summary.total_rows > 20`.

## State of the code in this folder
- `scrape.js` — adapted to Zepto (URL `https://www.zeptonow.com/`, GPS-based
  location via Playwright `geolocation`, 403 guard). Card-extraction logic is
  the portable geometry heuristic from Blinkit and is **UNVERIFIED** (the page
  never loaded from this IP).
- `build_excel.py` — platform-aware (derives "Zepto" from the folder name);
  identical to Blinkit's otherwise. Untested for Zepto (no data yet).
- NOT added to `setup_cron.sh` / `healthcheck.sh` — only live platforms go there.
